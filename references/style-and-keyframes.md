# 第 3–4 步：定画风、画设定图、出首尾帧

这两步由你写提示词，生图模型画图（默认 ChatGPT 图像 API，用 `scripts/imagegen.py`，见 `image-api.md`），用户负责看是不是想要的样子。**用户确认画风之前，不画正式镜头。**

## 第 3 步：定画风

画风就是这部片子的绘画风格。例如：宫崎骏式的手绘、柔和、暖色；线条简单的剪纸风；接近照片的写实风；美式动画的手绘线条感。有参考图最好，让用户发过来。

先画一两张样帧给用户挑，定下来后把画风写成一句固定描述，后面所有图片和视频提示词都复用这句话。

## 第 3 步：设定图

画风定下后，给每个角色和固定道具各画一张设定图：正面、侧面、几个表情。这一步等于把长相定死。

**人物身上固定的东西一定写清位置**，比如"纹身在左手臂上"。不写，后面每张图的纹身位置都可能不一样。

## 第 4 步：首尾帧

首尾帧就是每个镜头的第一张和最后一张画面。这是**降低抽卡率最关键的一步**：只靠文字生成视频，模型很容易出逻辑错误；雨、帽子、纹身这类东西只写在文字里根本不行，拍着拍着就没了，必须在首帧和尾帧里都画上。

### 绘制顺序

1. **先写后画**：不要一上来就画。先把每个镜头首帧画什么、尾帧画什么、中间发生什么写出来，交给审核 agent 过了再画。这样能省很多生图额度。
2. **先画内容最多的那张**，一般是尾帧，再在尾帧上改出首帧，保证两张图的机位和构图一致。
3. **同地点同机位的镜头**，直接在前一张图上改，不用重画（`imagegen.py gen --ref 原图.png` 走 edits 接口，提示词写"保持其他一切不变，只改……"）。
4. **推近镜头**：尾帧直接把首帧裁一块放大。首尾构图完全一样，视频就等于不动，没有推进效果。
5. **检查尺寸**：生图模型出的图不一定正好 16:9（或项目画幅，例如请求 2048×1152 实际给 1672×941），提交 Seedance 前用 `frames_util.py fit` 裁好，首帧和尾帧尺寸必须一致。推拉镜头用 `frames_util.py zoom` 以人物眼睛为中心按倍数裁，中心点的相对位置不变。

### 首尾帧检查（画完逐条查，每张图放大看）

```
首尾帧画完了，帮我按下面这些逐条检查，每张图都要放大看。有问题就告诉我是哪张图、哪里不对，我同意了再改。
材料：[首帧]、[尾帧]、[设定图]、[这个镜头的分镜]

1. 动作要用到的东西，首帧里必须有。比如后面要拿杯子，首帧里就要看得到杯子，否则杯子会凭空冒出来。
2. 别人的反应要提前摆好。一段视频就是一个镜头，没法中途切过去拍别人，所以首帧里要安排好：一个人在前面做事，另一个人在后面，脸朝着镜头。
3. 很多人一起出现时，不能摆同一个姿势，不然模型会让所有人同时动。
4. 给动作留出空间。东西要落到、飘到的地方要提前空出来，人的头顶也要留点空。
5. 风往哪边吹要统一，不能围巾往左飘，床单却往右飘。
6. 缩小到手机大小看一遍，远处的人太小、看不清就要改。
7. 放大看有没有多余的东西，比如多一个水壶，或者多一条奇怪的细线。
8. 把首帧和尾帧叠在一起看有没有错位。不该变的地方两张图必须一样。比如墙的颜色不一样，视频里墙就会慢慢变色；杯子大了一点，视频里杯子就会慢慢变大。

要改图的时候注意这几点：
- 生图模型就算只改一小块，也会把整张图重新处理一遍。所以只改一小块时，要把改好的那一块贴回原图；改完用 `frames_util.py diff` 看是否只有该改的地方变了。
- 服务商可能把 quality 自动降成 medium/low，细节不够就重试或换服务商。
- 额度用完了就等它恢复，不要买额度，也不要一次同时画太多张（并行 4–5 张以内）。
```

第 8 条可以用代码做：把首尾帧做差分图或半透明叠加，再放大看不该变的区域。
