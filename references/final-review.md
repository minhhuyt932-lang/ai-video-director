# 第 8 步：全片复核和交付

## 全片复核（新开子 agent，只给成片）

再新开一个审核 agent，只给它成片文件，不告诉它任何结论，让它像观众一样从头看一遍。

```
这是成片：[文件]。你第一次看，我不告诉你任何结论。
1. 全部解码，每镜取多张全分辨率帧，切点前后各取 3 帧。
2. 先写你看懂的故事，再列看不懂的地方。
3. 逐镜查：重复的动作、道具数量、穿帮、突跳、颜色跳变、脸变形、字的问题。
4. 明确写出你查不了的东西（动态手感、声音）。
每条写：时间、帧号、问题。分“硬伤”和“小问题”。
```

把复核结果交给用户：硬伤要修（按"先剪 → 代码修 → 改提示词重拍"的顺序），小问题由用户决定。动态手感和声音必须由用户亲自看、亲自听。

## 交付与经验沉淀

交付成片后，写一份项目总结存进项目文件夹（如 `NOTES.md`），把每次做片子的经验沉淀下来：

- 最终画风描述（可直接复用的那句话）和设定图路径
- 每个镜头最终用的提示词、模型、秒数、花费
- 犯过的错误：哪个镜头出了什么问题、原因、怎么修的或怎么改写提示词的
- 新发现的"模型易错 → 应该怎么写"条目
- 总花费和抽卡次数

下次做片子先读这份总结。
