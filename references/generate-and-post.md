# 第 6–7 步：生成视频，后期拼接、转场、调色、放大

## 第 6 步：生成视频

提交、轮询、下载用 `scripts/seedance.py`（接口细节见 `seedance-api.md`）。配置在项目根目录 `.env.local`（`SEEDANCE_API_KEY`、`SEEDANCE_BASE_URL`、`SEEDANCE_MODEL`），脚本自己读取，不打印 key。第一次先拿一个最短的镜头试通。下载的片段按镜头和版本号存，比如 `clips/shot03_v2.mp4`。

```
S=<skill目录>/scripts
.venv/bin/python $S/seedance.py run --name shot04_v1 --prompt prompts/shot04_v1.txt --first frames/s4_first.png --last frames/s4_last.png --duration 4 --out clips --dry-run
.venv/bin/python $S/seedance.py run --name shot04_v1 --prompt prompts/shot04_v1.txt --first frames/s4_first.png --last frames/s4_last.png --duration 4 --out clips
.venv/bin/python $S/clipcheck.py clips/shot04_v1.mp4 --first frames/s4_first.png --last frames/s4_last.png --out clips/check
```
- 2–3 条并行提交（个人账号并发上限 3）。720p、4–6 秒每条大约 3–5 分钟。
- 视频地址只保留 24 小时，脚本拿到就下载。
- `clipcheck.py` 的总表和对比图在 `clips/check/<片段名>/` 下。它会列出帧间差最大的几处：远大于中位数、又不在第 0–1 帧的，多半是"跳到尾帧"之类的突跳，按帧号逐帧看。

### 省钱技巧

- 用 **720p** 生成，后期再放大到 1080p。
- **不专门拍测试片**，直接拍第一个正式镜头，能用就赚了。
- **新做法先拿一两个最难的镜头试**，行得通再全部提交。
- **想清楚要不要用 Seedance 2.5**：官方价格约是 2.0 mini 的 3 倍。不是特别复杂、特别考验模型的镜头，2.0 mini 就够用；预算紧就用 2.0 mini。先问用户的 key 能不能调用 2.0 mini，能的话用 `seedance.py --model` 切换（key 不同就用 `--env` 指向另一份配置）。
- **声音听过再用**：2.0 mini 自带的音效经常能直接用。2.5 就算写了“没有音乐”，有时还是会混进音乐，这种就不用，音效后期另外加。你听不到声音，要请用户听。

### 出了问题，先别重拍

重拍又要花钱。按这个顺序考虑：

1. **能不能剪掉？** 问题只在开头或结尾几帧，直接剪掉。
2. **能不能用代码修？** 先尝试写代码修（调色、裁切、补推镜、冻结帧等），修不好再考虑重拍。
3. **要重拍，先改提示词或首尾帧**。原样再拍一次，大概率还是错的。只重拍这一镜，提交前同样要过审核 agent。
4. **旧片段不删**。重拍的不一定比旧的好，都留着，最后放在一起挑。都是花钱拍的，能用就用上。

## 第 7 步：后期（全部用代码做）

片段是一段段生成的，生成完后用 `.venv/bin/python <skill目录>/scripts/cut.py edit.json out.mp4` 按 JSON 剪辑表拼接成完整视频（按帧剪切、推近、定格、只调彩度亮度、601→709、lanczos 放大加锐化、可垫配乐、响度标准化）。剪辑表的写法见脚本开头。

```
用代码做后期：
1. 转场：[哪一镜到哪一镜，用什么东西盖屏或带过去]。运动模糊切 8–16 份，半帧快门。
2. 调色：按故事分段。只调彩度和亮度，不动色相，强调色受保护，肤色不变。不加颗粒、柔光、暗角。
3. Seedance 的 mp4 按 BT.601 解码，中间文件用无损格式，交付标 BT.709。
4. 放大：720p 用 lanczos 放大到 1080p，加轻微锐化。不用整段插帧。
5. 按小节卡点：拍点只从原曲上测，不要在剪过的文件上测。
做完抽查切点前后 3 帧。
```

同时处理第 5 步对照表里属于后期的问题：

- Seedance 2.5 第一帧特别锐 → 入点避开第 0–1 帧。
- Seedance 2.5 结尾几帧跳到尾帧的样子 → 选一张没问题的画面，后面都停在这一张。跳的位置正好在两个表情或动作之间时，可以剪掉过渡帧，把跳过去的那段推近 1.1 倍，做成有意的跳切（`cut.py` 的 `zoom`），不用重拍。
- Seedance 2.0 mini 越到后面越暗越冷 → 按该片段自己的首帧把颜色调回来。
- 推镜不够明显 → 用代码再推一点。
- 动作时间对不上节拍 → 剪辑加变速。
- 片段自带声音不可用 → 去掉，后期另加音效。
- 结尾定格时声音突然断成静音 → 定格段继续用原片后面的声音，再淡出 0.6 秒（`cut.py` 的 `freeze` 已这样处理）。
- 各镜饱和度、亮度不一致 → 先量每镜平均饱和度和亮度，只用 `eq=saturation`/`eq=gamma` 往相邻镜头靠，不动色相。
- 整片音量偏小（片段自带声音峰值常在 -10 dB 左右）→ `loudnorm` 标准化到 -16 LUFS。

你看不到真正的动态。抽帧检查完后，要明确告诉用户哪些只看了静帧、需要他们看动态和听声音确认。
