# 第 2 步：分镜——镜头语言、构图和配色

这是前期最重要的一步，决定了片子的质量。构图和配色甚至比剧情更重要：故事再好，镜头没设计好，画面就平淡。

## 参考片优先

镜头语言（推拉横移、机位摆放）很难用嘴描述清楚。最有效的办法是找参考片：逐帧看参考片，把机位、进出画比例这些量出来，然后学习模仿。没有参考片，就按下面的要求自己构思。

## 每个镜头必须写清

景别、机位、运镜、谁往哪走（写画面的左右）、靠什么表情推进、这个镜头是什么在动、怎么转到下一镜。

## 镜头语言 6 条要求

1. **每镜换角度**：全片平视正面最多两次，其余用俯拍、仰拍、从背后、过肩、透过东西拍。机位越多，画面越丰富。
2. **画面里要一直有东西在动**：人不动、东西也不动，观众就像在看一张图片——"画面死了"。大多数镜头要有人或东西走进/走出画面。人坐着不动，就让别的东西动：飘过的一张纸、身后走过的路人。固定机位很容易呆板，更要让人在画面里走动，比如从远走到近。也不要连着几个镜头画面大小一样，全身、半身、脸部特写换着来。
3. **写清楚具体是什么在动**：摄影机、焦点（从一个人换到另一个人）、光线、镜头前飘过的东西、人物小动作（如手在抖），至少要有一样。一样都写不出来，说明这个镜头还没想好。但也不要全片一直晃：该动的动，该静的静，才有对比。
4. **镜头运动要有理由**：摄影机动一下，一定是有东西想给观众看。最常用三种：跟着一个人或物走（信飞到哪镜头跟到哪）；慢慢推近给特写；从近处慢慢拉远。
5. **每一秒截图都要好看**：用黄金比例构图，人的头或眼睛落在画面从左往右约 38% 或 62% 的位置，不放正中间。
6. **配色单独设计**：配色不交给模型自己发挥，画第一张图前就定好。把每一场用什么颜色单独列成一张色表。最后把画面转成黑白看一遍，人和背景分不开说明明暗对比不够，要重调配色。可以先用 `scripts/contrast_check.py` 算主体和紧挨着的背景的亮度差，<40 就改色（常见：肤色和米色墙、浅色衣服和浅色沙发）。

## 提示词：分镜

```
把定稿的故事写成分镜表。每个镜头一行，写清楚：片中时间（配歌就按小节算）、生成秒数（片中时长加 0.5 秒后向上取整，不足 4 秒按 4 秒；Seedance 2.5 只接受 4–30 的整数秒）、景别、机位、运镜、谁往哪走（写画面的左右）、靠什么表情推进、这个镜头是什么在动、怎么转到下一个镜头。

如果有参考片，先逐帧看参考片，把机位、进出画比例这些都量出来，然后学习模仿。没有参考片就按下面的要求自己构思。

要求：
1. 每个镜头换角度。全片平视正面最多两次，其余用俯拍、仰拍、从背后、过肩、透过东西拍。
2. 画面里要一直有东西在动。大多数镜头都要有人或者东西走进画面，或者走出画面。人不走动的镜头，就让别的东西动起来，比如飘过去的一张纸，或者身后走过的路人。固定机位更要让人在画面里走动，比如从远处走到近处。
3. 不要连着好几个镜头都是一样大小的画面，全身、半身、脸部特写要换着来。
4. 每个镜头都要写清楚是什么在动：摄影机、焦点、光线、镜头前面飘过的东西，或者人物的小动作，至少要有一样。也不要一直动，该动的地方动，该静的地方静。
5. 镜头运动要有理由：跟着一个东西走，慢慢推近给特写，或者从近处慢慢拉远。
6. 每一秒截图都要好看。人的头或者眼睛落在画面从左往右大约 38% 或者 62% 的位置，不要放在正中间。

配色要单独设计，在画第一张图之前定好。我想要的配色：[我的喜好；没想好就给我几个方案选]。
把每一场用什么颜色单独列成一张色表。

最后用代码给每个镜头画一张 1920×1080 的色块草图，标出 38% 和 62% 的位置和主要的东西，拼成一张总表给我确认。再把草图转成黑白看一遍，如果人和背景区分不开，就说明明暗对比不明显，要重新调配色。
```

## 产出物

- 分镜表（每镜一行）
- 色表（每场用色）
- 色块草图总表（1920×1080/镜，含 38%/62% 参考线）及其黑白版

分镜表同样可以交给新开的审核 agent 看一遍（只给分镜表，不给结论），用户确认后进入下一步。
